# Employee Names

> **Topic:** Basic Select<br>
> **Difficulty:** Easy<br>
> **HackerRank:** <https://www.hackerrank.com/challenges/name-of-employees/problem?isFullScreen=true>

## Intuition / Approach

Approach:

1. TABLE: Employee
2. COLUMNS: name
3. Order the results by name alphabetically

## My Solution

```sql
SELECT name
FROM Employee
ORDER BY name ASC;
```

## Reflection

Refreshed on ORDER BY in ascending order.
